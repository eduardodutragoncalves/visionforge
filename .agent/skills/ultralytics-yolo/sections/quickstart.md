# Quickstart

## Install
Prefer pip install ultralytics and verify `yolo` is available.

## Core mental model
Choose:
- TASK: detect/segment/classify/pose/obb
- MODE: train/val/predict/export/track/benchmark :contentReference[oaicite:5]{index=5}
Then run:
`yolo TASK MODE arg=value ...` :contentReference[oaicite:6]{index=6}
